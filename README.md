# HUD Screenshot Merger (進捗画像キャプチャ)

AviUtl2の編集状況を一枚の画像にキャプチャしてくれる汎用プラグイン`aux2`です。
`ファイル->エクスポート`から実行できます。

---
# 謝辞
このプラグインは`aviutl2-cli`を用いて開発されています。
詳細は`https://github.com/sevenc-nanashi/aviutl2-cli`をご覧ください。
