# HUD Screenshot Merger (進捗画像キャプチャ)

AviUtl2 (ExEdit2) 向けの進捗画像キャプチャ＆合成汎用プラグイン（`.aux2`）です。

タイムラインやプレビュー画面からワンクリックで、現在編集中の動画フレームを高画質レンダリングし、下部に Notion / Figma 風のモダン・ミニマリストな「進捗情報 HUD（情報表示パネル）」を美しく結合した PNG 画像を出力します。

SNS（X / Discord 等）への動画制作進捗の共有を、美しく、ワンアクションで行うことができます。

---

## 主な特徴

- 🎯 **SDK ネイティブレンダリング**: OS のウィンドウキャプチャではなく、AviUtl2 公式 SDK の `rendering_scene_video` から直接 RGBA ピクセルを取得。UI やマウスカーソルの被り、DPI スケールによる歪みが一切ありません。
- 🖤 **透明背景・白飛び対策**: 未描画領域を黒背景と合成して不透明化するため、画像ビューアや SNS に投稿しても背景が透けて白飛びしません。
- 🎨 **6 種類の洗練された配色パレット**:
  - **ダーク (Dark)**: 完成された Zinc ミニマルダーク
  - **ライト (Light)**: Notion 風クリーンホワイト & チャコール
  - **春 (Spring / Sakura)**: 墨桜（スモーキーローズ & 淡桜白）
  - **夏 (Summer / Ocean)**: 深海（ディープネイビー & ターコイズスカイ）
  - **秋 (Autumn / Amber)**: 琥珀・紅葉（ウォールナットダーク & 温白色）
  - **冬 (Winter / Frost)**: 白銀・氷藍（凍夜スレート & フロストインディゴ）
- 👤 **@ユーザー名 クレジット表記**: プラグイン設定から任意のユーザー名を設定可能。
- ⚡ **シームレスな共有体験**: 保存完了時に自動で既定のフォトビューアを開くオプションを搭載。
- 🖥️ **AviUtl2 公式準拠の設定ダイアログ**: Windows 11 ネイティブの角丸コントロールと整然とした 2 カラムレイアウトを採用。

## 使い方

以下のいずれかの操作でいつでも即座に実行できます：

1. **プレビュー画面**: プレビュー画面上で右クリックし、「**進捗画像をキャプチャして保存...**」を選択
2. **メニューバー**: 「**ファイル**」 -> 「**エクスポート**」 -> 「**進捗画像をキャプチャして保存...**」を選択
3. **タイムライン**: タイムラインまたはオブジェクトを右クリックし、「**進捗画像をキャプチャして保存...**」を選択

### 設定の変更
メニューバーの「**設定**」 -> 「**プラグイン**」 -> 「**HUD Screenshot Merger**」を開きます。
- ユーザー名の変更
- 配色パレットの切り替え（6 色）
- 保存完了時に画像を開くかどうかの切り替え

## ビルド方法

本プロジェクトは `aviutl2-cli` (`au2`) および CMake (C++20) に対応しています。

### 必要環境
- Windows 10 / 11 (64bit)
- Visual Studio 2022 (MSVC / C++20)
- CMake 3.20 以上
- `aviutl2-cli` (`au2`)

### コマンド
```powershell
# 開発環境の準備 (SDK submodule 更新・シンボリックリンク作成)
au2 prepare

# 開発用ビルド (本体は起動しない)
au2 dev --skip-start

# 開発用 AviUtl2 を起動して実機テスト
au2 dev

# 配布用パッケージ (.au2pkg.zip) の生成
au2 release
```
